Dashboard Template

This is a **Bootstrap 5 Admin Dashboard Template** inspired by Elzero Web School design.

## Features

- Responsive layout using Bootstrap grid
- Last Project Progress with blinking indicator
- Reminders section with colored dots and timeline
- Latest Post card with user info, post text, likes, and comments
- Social Media Stats cards with icons and follow buttons
- Projects Table:
  - Overlapping team avatars
  - Progress bars
  - Status badges (Pending, Completed, Rejected, In Progress)

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Font Awesome Icons
